# MCP Registry schema

This directory holds the official JSON Schema used to check `server.json` before
a release. Validation runs offline:

```bash
npm run check:registry
```

`mcp-server-2025-12-11.schema.json` is an unmodified copy of the
[official registry schema](https://static.modelcontextprotocol.io/schemas/2025-12-11/server.schema.json),
downloaded on 2026-09-07.

SHA-256: `3fba09590c99f61735d234822279f4223fab9e300c0a81e81c91ab62a4114de0`.

The source is generated by the [MCP Registry](https://github.com/modelcontextprotocol/registry)
from `docs/reference/api/openapi.yaml`. The schema itself records its origin in
`$comment`. The check validates the complete document, including formats and
nested definitions. Neither the schema nor this guide ships in the npm package.

To update the schema, review the upstream changes, replace the schema bytes, and
update the pinned digest in `scripts/check-registry-schema.mjs` and this guide in
the same change. Keep the upstream license beside the downloaded file.

The upstream [license](https://github.com/modelcontextprotocol/registry/blob/main/LICENSE)
is preserved in `LICENSE` alongside the schema, including its licensing transition
notice. This does not change the license of this project's original code.
